Project သည် AndroidX ဖြစ်ကြောင်း စစ်ပါ။ Sketchware Local Library Manager သည် Maven dependency အားလုံးကို Gradle ကဲ့သို့ မဖြေရှင်းနိုင်ပါ။ မရပါက AAR/JAR နှင့် transitive dependencies များ လိုအပ်နိုင်သည်။
  • Glide နှင့် Picasso ထဲမှ တစ်ခုသာရွေးပါ။
  • Gson နှင့် Fastjson2 ထဲမှ parser တစ်ခုသာရွေးပါ။
  • Firebase တွင် BOM သုံးပါ။ Supabase တွင် service_role key ကို app ထဲ မထည့်ပါနှင့်။
  • Library တစ်ခုချင်းစီထည့်ပြီး build စမ်းပါ။

Build မလုပ်မီ Checklist

  1. Project ကို backup/export လုပ်ပါ။
  2. Library တစ်ခုချင်းစီကို ထည့်ပြီး build စမ်းပါ။
  3. Duplicate class, Manifest merger failed, minSdk error များ စစ်ပါ။
  4. android.support.* နှင့် AndroidX ကို မရောသုံးပါနှင့်။
  5. Network request ကို main/UI thread တွင် မလုပ်ပါနှင့်။
  6. API key နှင့် Firebase/Supabase secret များကို public repository ထဲ မတင်ပါနှင့်။
