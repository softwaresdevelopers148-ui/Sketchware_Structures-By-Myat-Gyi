အခန်း (၄) - Components & MoreBlocks

၁။ Components (အဆင့်မြင့် Function နှင့် Background Service များ)

Component အသုံးပြုပုံ ရှင်းလင်းချက်
Intent Screen အသစ်တစ်ခုသို့ ကူးပြောင်းရန် သို့မဟုတ် တခြား App များသို့ Data ပို့ရန် (ဥပမာ- Browser ဖွင့်ခြင်း)။
SharedPreferences App ပိတ်လိုက်သော်လည်း Data လေးများကို ဖုန်းထဲတွင် အမြဲတမ်း သိမ်းဆည်းထားရန် (ဥပမာ- Login Status, Theme Mode)။
Calendar ရက်စွဲနှင့် အချိန်ဆိုင်ရာ Data များကို တွက်ချက်ရယူရန်။
Timer အချိန်ပိုင်းအလိုက် ခဏစောင့်ဆိုင်းစေရန် သို့မဟုတ် ပုံမှန် အချိန်ခြားပြီး Logic Run ရန်။
Dialog Popup Box ဖိပြပြီး သတိပေးစာပြသရန် သို့မဟုတ် User ထံမှ အတည်ပြုချက်တောင်းရန်။
MediaPlayer / SoundPool အသံဖိုင်များနှင့် Sound Effect များကို စီမံဖွင့်လှစ်ရန်။
Firebase (DB/Auth/Storage) Realtime Database သုံးရန်၊ User Account ဝင်ရန်နှင့် Cloud ပေါ် ဖိုင်တင်ရန်။
RequestNetwork API ခေါ်ယူရန်၊ Web Server များနှင့် Data အကူးအပြောင်း ပြုလုပ်ရန် (HTTP GET/POST)။
Notification ဖုန်း၏ Notification Bar တွင် အကြောင်းကြားစာ ပြသရန်။

၂။ MoreBlock (Custom Function/Block များ ဖန်တီးခြင်း)

အသုံးပြုရသည့် ရည်ရွယ်ချက်: Code ထပ်ခါထပ်ခါ ရေးရခြင်းမှ ရှောင်ရှားရန်နှင့် Logic များကို သန့်ရှင်းသပ်ရပ်စွာ စုစည်းထားရန်။
Return Type ပြန်ပေးမည့် Data အမျိုးအစား ရှင်းလင်းချက်
Void မည်သည့် Data မှ ပြန်မပေးဘဲ Logic Action တစ်ခုတည်း လုပ်ဆောင်မည်။
String စာသား Data ပြန်ပေးမည်။
Number ကိန်းဂဏန်း Data ပြန်ပေးမည်။
Boolean True / False စစ်ဆေးချက် ပြန်ပေးမည်။
Parameter Type ပါဝင်နိုင်သော Argument များနှင့် အသုံးပြုပုံ
Variable MoreBlock ထဲသို့ String, Number, Map စသည့် Data ထည့်သွင်းပေးပို့ရန်။
View Specific ဖြစ်သော TextView, Button, ImageView များကို Argument အဖြစ် လက်ခံရန်။
Component Intent, Timer, SharedPreferences စသည်တို့ကို တိုက်ရိုက် Parameter အဖြစ် သုံးစွဲရန်။
