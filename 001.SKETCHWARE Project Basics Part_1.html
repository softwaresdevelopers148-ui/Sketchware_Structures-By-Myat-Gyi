Sketchware Pro • Beginner Series

App Starting Guide — Part 1

Sketchware Pro ၏ အခြေခံ တည်ဆောက်ပုံနှင့် အပိုင်းအလိုက် အသုံးပြုပုံဆိုင်ရာ အသေးစိတ် မှတ်စု။

၁။ Project Creation ၂။ Layouts ၃။ AndroidX Layouts ၄။ Properties Panel

အခန်း (၁) - App တည်ဆောက်ခြင်း အခြေခံ (Project Creation & View Layout)

၁။ Project Creation (ပရောဂျက်အသစ် စတင်ခြင်း)

Item ရှင်းလင်းချက်
Application Name App ၏ နာမည်ကို သတ်မှတ်ပေးသည့်နေရာ ဖြစ်သည်။
Package Name com.my.newproject ပုံစံ App ၏ သီးသန့် Identifier ဖြစ်ပြီး Play Store တင်ရာတွင် သို့မဟုတ် တခြား App များနှင့် မထပ်စေရန် သီးသန့်ပေးရသည်။
Project Name Sketchware အတွင်း စီမံခန့်ခွဲရန် Project Identifier ဖြစ်သည်။
Color Schemes Color Accent, Primary, Primary Dark စသည်ဖြင့် App ၏ Theme အရောင်များကို စတင်သတ်မှတ်နိုင်သည်။

၂။ Layouts (မျက်နှာပြင် အပြင်အဆင် ရေးဆွဲခြင်း)

Layout အသုံးပြုပုံ
Linear (H) / Linear (V) UI Element များကို ရေပြင်ညီ (Horizontal) သို့မဟုတ် ဒေါင်လိုက် (Vertical) တန်းစီစီစဉ်ပေးသည့် အခြေခံ Box များဖြစ်သည်။
Scroll (H) / Scroll (V) စခရင်ထက် ပိုရှည်သော Content များကို အထက်အောက် သို့မဟုတ် ဘေးတိုက် Scroll ဆွဲကြည့်နိုင်အောင် ပြုလုပ်ပေးသည်။
RadioGroup RadioButton များကို စုစည်းထားပြီး တစ်ခုတည်းကိုသာ ရွေးချယ်စေချင်သည့်အခါ အသုံးပြုသည်။

၃။ AndroidX Layouts (အဆင့်မြင့် Visual Layout များ)

Component အသုံးပြုပုံ
CardView Rounded Corner နှင့် Shadow (အရိပ်) ပါဝင်သော Card ပုံစံ Box များပြုလုပ်ရာတွင် သုံးသည်။
TabLayout & BottomNavigationView App ၏ Tab Menu များနှင့် အောက်ခြေ Main Menu အကူးအပြောင်းပြုလုပ်ရန် သုံးသည်။
TextInputLayout Text ရိုက်ထည့်စဉ် Floating Hint (စာရိုက်ရင် စာတန်းလေး အပေါ်ကြွတက်သွားသည့်ဒီဇိုင်း) ရရှိစေရန် သုံးသည်။
SwipeRefreshLayout စခရင်ကို အောက်သို့ဆွဲချ၍ Data သစ်များ Refresh လုပ်သည့် Function ထည့်သွင်းရန် သုံးသည်။

၄။ Properties Panel (UI များ၏ Property သတ်မှတ်ချက်များ)

Property ရှင်းလင်းချက်
ID Code အပိုင်းတွင် အဆိုပါ Widget ကို ခေါ်ယူသုံးစွဲရန် သီးသန့်ပေးရသော နာမည်ဖြစ်သည်။
Width / Height Widget ၏ အကျယ်နှင့် အမြင့် (Match Parent, Wrap Content သို့မဟုတ် dp သတ်မှတ်ချက်) ဖြစ်သည်။
Padding & Margin Box အတွင်းပိုင်း စာနှင့် အနားသတ်ကြား အကွာအဝေး (Padding) နှင့် Box များတစ်ခုနှင့်တစ်ခု အပြင်ဘက်မှ ခွာသည့် အကွာအဝေး (Margin) ဖြစ်သည်။
Gravity / Layout Gravity Text သို့မဟုတ် Widget ၏ တည်နေရာကို ဗဟို၊ ဘယ်၊ ညာ ညှိယူပေးသည်။
Text Properties Text, Text Size, Text Style, Text Color စသည်ဖြင့် စာသား၊ စာလုံးအရွယ်အစား၊ Font Bold/Italic နှင့် အရောင် သတ်မှတ်ပေးသည်။
မြတ်ကြီး မှ ယခု SKETCHWARE Project Basics အား ထည့်အသုံးပြုပုံ နှင့် လင့်များအား နားလည် အသုံးပြုရလွယ်ကူစေရန် ဖန်တီးပေးထားပါသည်။
