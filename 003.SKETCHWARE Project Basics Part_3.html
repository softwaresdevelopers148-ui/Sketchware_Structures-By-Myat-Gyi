၁။ Event Types ၂။ Logic Category & Block Palette

အခန်း (၃) - Event, Logic & Block Coding System

၁။ Event Types (အဖြစ်အပျက်နှင့် သက်ဆိုင်သော Trigger များ)

Event Category Event Name ရှင်းလင်းချက်
Activity
(Life Cycle Events)		 onCreate App (သို့) Screen စဖွင့်ဖွင့်ချင်း ပထမဆုံး အလုပ်လုပ်မည့် Logic ရေးရန်။
onStart / onResume Screen ပေါ်ထွက်လာချိန် / User ပြန်သုံးသည့်အချိန်များတွင် Data သစ်ပြန်ခေါ်ရန်။
onPause / onStop App ခဏ ပိတ်ထားချိန် သို့မဟုတ် အနောက်ရောက်သွားချိန်တွင် Data သိမ်းရန်။
onBackPressed ဖုန်း၏ Back Button ကို နှိပ်လိုက်သည့်အခါ ပြုလုပ်မည့် Action ရေးရန်။
View Events onClick Widget (Button/Image) ကို တစ်ချက် နှိပ်လိုက်သည့်အခါ အလုပ်လုပ်ရန်။
onLongClick Widget ကို ဖိနှိပ်ထားသည့်အခါ (Long Press) Action ပြုလုပ်ရန်။
Component Events Callbacks Component တစ်ခုချင်းစီ၏ Callback Event များ (ဥပမာ- Intent, Firebase Data ရောက်လာချိန်)။

၂။ Logic Category & Block Palette (Code Block အမျိုးအစားများ)

Category အသုံးပြုပုံ ရှင်းလင်းချက်
Variable (ကိန်းရှင်များ) Boolean (True/False), Number, String (စာသား) နှင့် Map Data များကို ယာယီသိမ်းဆည်း/ပြင်ဆင်ရန်။
List (စာရင်းများ) String List, Number List သို့မဟုတ် Map List များ ဖန်တီး၍ Data များကို အစဉ်လိုက် စီမံရန်။
Control (အကန့်အသတ်နှင့် စက်ဝန်းများ) if ... else — အခြေအနေ စစ်ဆေး၍ လုပ်ဆောင်ချက် ခွဲခြားရန်။
repeat / for loop — ပေးထားသော ပမာဏအတိုင်း ထပ်ခါထပ်ခါ အလုပ်လုပ်ခိုင်းရန်။
Operator & Math (တွက်ချက်မှုနှင့် စစ်ဆေးမှုများ) စာသားချင်း ဆက်ရန် (join), သင်္ချာတွက်ချက်ရန် (+, -, *, /), ညီမညီ စစ်ဆေးရန် (=, >, <)။
File (ဖိုင်စီမံခန့်ခွဲမှု) ဖုန်း Storage ထဲသို့ ဖိုင် ရေးခြင်း (Write), ဖတ်ခြင်း (Read), ကူးခြင်း (Copy) နှင့် ဖျက်ခြင်း (Delete)။
View Blocks UI များ၏ စာသားပြောင်းရန် (setText), အရောင်ပြောင်းရန် (setTextColor), မြင်ကွင်း ဖျောက်/ပြ လုပ်ရန် (setVisible)။
မြတ်ကြီး မှ ယခု SKETCHWARE Event, Logic & Block Coding System အား ထည့်အသုံးပြုပုံ နှင့် လင့်များအား နားလည် အသုံးပြုရလွယ်ကူစေရန် ဖန်တီးပေးထားပါသည်။
