အခန်း (၂) - Widgets, Custom Libraries & Configuration Settings

၁။ Basic & Advanced Widgets (အခြေခံနှင့် အဆင့်မြင့် View များ)

Widget အသုံးပြုပုံ ရှင်းလင်းချက်
TextView / EditText စာသားပြသရန် / အသုံးပြုသူထံမှ စာသားရိုက်ထည့်မှု လက်ခံရန်။
Button / MaterialButton နှိပ်လိုက်သည့်အခါ Action တစ်ခုခု လုပ်ဆောင်ရန်။
ImageView / CircleImageView ပုံမှန် ဓာတ်ပုံ သို့မဟုတ် အဝိုင်းပုံ ဓာတ်ပုံများ ပြသရန်။
CheckBox / Switch On/Off သို့မဟုတ် True/False ရွေးချယ်မှုများ ပြုလုပ်ရန်။
ProgressBar / SeekBar Loading ပြသရန်နှင့် Value ပမာဏ အတိုးအလျှော့ ပြုလုပ်ရန် (ဥပမာ- Sound Volume)။
ListView / RecyclerView Data များကို စာရင်းလိုက် (List) ပုံစံဖြင့် အများအပြား ပြသရန်။
WebView App အတွင်း Web Page / Website များ တိုက်ရိုက်ဖွင့်ကြည့်ရန်။

၂။ External Library Views (အထူးပြု Library များ)

Library View အသုံးပြုပုံ ရှင်းလင်းချက်
LottieAnimation GIF ထက် ပေါ့ပါးသော Lottie JSON Animation များ ပြသရန်။
CodeView Source Code များကို Syntax Highlighting ဖြင့် ပြသရန်။
BadgeView Notification Icon ပေါ်တွင် အရေအတွက် စာတွဲများ ပြသရန်။
WaveSlideBar လှိုင်းပုံစံ Animation ပါသော SlideBar UI ပြုလုပ်ရန်။
PatternLockView Pattern လှို့ဝှက်နံပါတ် သတ်မှတ်သည့် UI စနစ် ထည့်သွင်းရန်။

၃။ Project Configuration & Injection Tools (အကူအညီပေးစနစ်များ)

Tool / Option ရှင်းလင်းချက်
Library AppCompact, Firebase, AdMob, Glide စသည့် Library များ Enable/Disable လုပ်ရန်။
View / Image / Sound / Font Screen (Activity) အသစ်များ တိုးခြင်း၊ ပုံများ၊ အသံများနှင့် Custom Font (.ttf) များ ထည့်သွင်းစီမံရန်။
Java / Resource / Asset External Java File များ၊ Native XML Resource များနှင့် Offline Asset File များ ထည့်သွင်းရန်။
AndroidManifest Permission ထည့်ခြင်း၊ App Orientation နှင့် Service များ ပြင်ဆင်ရန်။
Custom Blocks မိမိကိုယ်ပိုင် သီးသန့် Block များ ဖန်တီး၍ သိမ်းဆည်းထားရန်။
ProGuard / StringFog Code များကို မသမာသူများ Reverse Engineering မလုပ်နိုင်အောင် Obfuscate လုပ်ပြီး ကာကွယ်ရန်။
Show Source Code Generator မှ ထွက်လာသော Java & XML Source Code များကို တိုက်ရိုက်ကြည့်ရှုရန်။
Logcat Reader App Crash ဖြစ်သည့် အမှား (Error Log) များကို စစ်ဆေးဖတ်ရှုရန်။
မြတ်ကြီး မှ ယခု SKETCHWARE Widgets & Configuration Settings အား ထည့်အသုံးပြုပုံ နှင့် လင့်များအား နားလည် အသုံးပြုရလွယ်ကူစေရန် ဖန်တီးပေးထားပါသည်။
