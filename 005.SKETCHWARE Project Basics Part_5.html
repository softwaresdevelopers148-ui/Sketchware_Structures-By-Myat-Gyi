Advanced App Concepts

Advanced App များ ရေးသားရာတွင် လိုအပ်သော အဆင့်မြင့် နယ်ပယ်များနှင့် နည်းပညာများဆိုင်ရာ အသေးစိတ် မှတ်စု။

၁။ API & JSON Parsing ၂။ Code Injection (ASD) ၃။ Offline Database ၄။ Custom Library & Block

ဖြည့်စွက် - Advanced App ရေးသားရာတွင် လိုအပ်သော အဆင့်မြင့် နယ်ပယ်များ

၁။ Advanced API & JSON Parsing

Topic အသေးစိတ် လုပ်ဆောင်ချက်
RequestNetwork Client RequestNetwork Block များကို သုံး၍ REST API များအား HTTP GET / POST Request များ ပေးပို့ခေါ်ယူခြင်း။
JSON Parsing & Display Google Sheets, Blogger API, 2D/3D Live API များမှ JSON Data များကို JsonArray / JsonMap သို့ ပြောင်းလဲ၍ ListView / RecyclerView တွင် စနစ်တကျ ဖော်ပြခြင်း။

၂။ Custom Java Code / Source Code Injection

Technique အသေးစိတ် လုပ်ဆောင်ချက်
ASD (Add Source Directly) Add Source Directly (ASD) Block များကို သုံး၍ Sketchware Standard Block တွင် မပါသော Java Code များကို တိုက်ရိုက် ရေးသားခြင်း။
Native Class Integration Custom Import, Custom Variable များနှင့် Native Android Class များကို တိုက်ရိုက် ခေါ်ယူ အသုံးပြုခြင်း။

၃။ Local Storage & Offline Database Management

Database Engine အသေးစိတ် လုပ်ဆောင်ချက်
Offline Storage Systems SQLite Database, Realm DB သို့မဟုတ် JSON File စနစ်များ သုံး၍ ဖုန်း Storage အတွင်း Offline Data များကို ဖွဲ့စည်းသိမ်းဆည်း စီမံခြင်း။

၄။ Custom Library (.aar / .jar) & Custom Block Making

Custom Tool အသေးစိတ် လုပ်ဆောင်ချက်
External Libraries Local Library Manager မှတစ်ဆင့် External Android Library (.aar / .jar) များကို ပရောဂျက်အတွင်း ထည့်သွင်းခြင်း။
Custom Block System မိမိကိုယ်ပိုင် Block Selector Menu (menu.json) နှင့် Block Spec (block.json) များ ဖန်တီး၍ အချိန်တိုအတွင်း Code ရေးသားနိုင်အောင် စီမံခြင်း။
